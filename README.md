# Sip Studies — Guild Crawler

A one-page WebGL demo: a crawler travels between eight beverage guilds (Water, Coffee, Tea, Wine, Beer, Spirits, Sake·Cider, Non-Alc), shooting tendrils to subtype tags while a live dashboard tracks the crawl.

**Live:** https://sip-coder.github.io/sip-guilds/

Static files only. Three.js 0.160.0 from unpkg (EffectComposer + UnrealBloomPass). Autoplays; respects `prefers-reduced-motion`; dashboard collapses on mobile. Previews in `previews/`.
